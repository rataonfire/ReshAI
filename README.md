# Проект генерации вариантов заданий

## Быстрый старт
1. `./setup_project.sh` — создать структуру (если не сделано)
2. `docker compose up -d` — поднять БД, Redis, MinIO
3. Для ML-разработки: `docker compose --profile ml up -d ollama`
4. Бэкенд: `cd backend && pip install -r requirements.txt`
5. ML: `cd ml && pip install -r requirements.txt`

## Структура
- `frontend/` — React (Надя)
- `backend/` — FastAPI (Вика)
- `ml/` — LangChain, промпты, RAG (Добрыня)
- `data/` — сырые и обработанные данные
- `init/` — SQL для автоматической инициализации БД

## 2. Техническое описание решения 

### 2.1 Интеграция с LLM и используемые промпты

**Модели:**
- **Генератор вариантов:** GigaChat Pro (пакет 3M токенов)
- **Критик / валидатор:** Qwen 7B (через Ollama, локально)
- **Классификатор типа задания:** GigaChat Lite (экономичный)

**Промпты (краткое описание):**

| Назначение | Модель | Вход → Выход |
|------------|--------|---------------|
| Классификация типа задания | GigaChat Lite | `текст задания` → `{"task_type":"word_problem", "complexity":"simple"}` |
| Анализ инвариантов и вариативных частей | GigaChat Pro | `текст + task_type` → `{"invariant":"...", "variables":[{"type":"number", "value":5}]}` |
| Генерация N вариантов (few-shot) | GigaChat Pro | `инвариант + variables + кол-во + типы вариации` → `[{"text":"...", "answer":"..."}]` |
| Критика / проверка корректности | Qwen 7B | `оригинал + вариант` → `{"valid": true/false, "issues":[...]}` |

!путь промтов уточнить!
*Полные промпты находятся в репозитории: `/ml/prompts/`.* 

### 2.2 Парсинг загружаемых форматов

| Формат | Инструмент | Действие |
|--------|------------|----------|
| `.txt` | встроенный `open()` | чтение как UTF-8 |
| `.pdf` (текстовый слой) | `pdfplumber` | извлечение текста постранично |
| `.pdf` (скан/картинка) | `pytesseract` + `Pillow` | OCR русский язык |
| `.docx` | `python-docx` | извлечение текста из параграфов |
| `.pptx` | `python-pptx` (опционально) | извлечение текста со слайдов |
| `.png/.jpg` | `pytesseract` | OCR изображения |

**Математические формулы:** при наличии сложных выражений вызывается `pix2tex` (конвертация в LaTeX) или LLM‑нормализатор.

### 2.3 Механизм хранения данных

- **СУБД:** PostgreSQL 16 + расширение `pgvector`
- **ORM:** SQLAlchemy 2.0 (асинхронный)
- **Основные таблицы:**
  - `tasks` — исходные задания (текст, инвариант, переменные, предмет, класс, тип)
  - `variants` — сгенерированные варианты (текст, ответ, уровень верификации)
  - `generation_sessions` — сессии пользователей
  - `corpus_tasks` — библиотека задач из учебников (+ эмбеддинги для RAG критика)
- **Кэш и лимиты:** Redis (счётчики запросов к LLM, временное кэширование)

### 2.4 Реализация ограничений и форматов

#### Ограничение запросов к LLM на пользователя
- **Инструмент:** `slowapi` (FastAPI middleware)
- **Правило:** 10 запросов `/generate` в минуту на один `session_id`
- **Хранение счётчиков:** Redis (TTL = 60 сек)
- **При превышении:** HTTP 429 Too Many Requests

#### Форматы экспорта и воспроизведения (кейс №4)
- **PDF экспорт:** комплект вариантов с маркировкой «Вариант 1, 2…» + отдельный лист с ответами для учителя. Генерация через `reportlab`.
- **DOCX экспорт:** через `python-docx` (шаблон с возможностью редактирования в MS Word).
- **Веб-интерфейс:** параллельный просмотр всех вариантов (многопанельный режим) с возможностью редактирования (WYSIWYG).
- **Персональные ссылки (дополнительно):** `[будет реализовано / не реализовано]` — если да, то уникальный session ID без авторизации.

## 3. Краткие шаги по запуску MVP (локально)

```bash
# 1. Клонировать репозиторий
git clone [URL репозитория]
cd project

# 2. Создать .env на основе .env.example (заполнить недостающие ключи)
cp .env.example .env

# 3. Запустить контейнеры (PostgreSQL, Redis, Ollama)
docker-compose up -d

# 4. Установить Python-зависимости
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # Windows
pip install -r requirements.txt

# 5. Применить миграции БД
alembic upgrade head

# 6. Запустить бэкенд
uvicorn backend.main:app --reload

# 7. Фронтенд (отдельно)
cd frontend
npm install
npm run dev
